# RepoQA 2024-06-23 固定数据集

该目录固定 RepoQA `2024-06-23` 发布包，用于外部仓库级 Path 定位和原文片段检索评测。

固定数据实际包含6种语言、60个真实GitHub仓库、600题和8775个源文件。其中37个上游空文件没有题目以其为目标。

## 准备与校验

```bash
python3 repoqa.py prepare
python3 repoqa.py verify
```

脚本只使用Python标准库。固定发布包下载到`.work/`并校验SHA-256，不提交或重新分发上游源码。具体系统的评测运行器由被测项目实现。

## 评测口径

- `Path Recall@5/10`：目标函数所在文件是否进入前5/10个命中文件；
- `Function span hit`：返回的原文命中位置是否落在目标函数范围；
- 搜索输入只能来自官方自然语言描述，不能读取目标函数名、目标Path或标准正文；
- 该数据集是检索内核的外部对照，不代表Codex或Claude最终回答准确率。

RepoQA项目为Apache-2.0；发布包内的上游仓库源文件仍受各仓库许可证约束。
